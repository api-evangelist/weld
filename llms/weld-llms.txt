# Weld

> Weld is a programmable data-infrastructure platform for near real-time ELT/ETL, log-based Change Data Capture, SQL data transformations, and Reverse ETL, with 300+ prebuilt connectors. The Weld Connect REST API and a hosted MCP server let developers and AI agents create connections, run and monitor syncs, build transforms, and orchestrate pipelines. Copenhagen-based, backed by a16z. (Generated by the API Evangelist enrichment pipeline from the Weld developer surface — not an official Weld llms.txt.)

## APIs
- [Weld Connect API reference](https://weld.app/docs/api-reference): REST API to control connections, ELT syncs/streams, transforms, orchestrations, and Reverse ETL. Base URL https://connect.weld.app. Auth: API key in x-api-key header.
- [OpenAPI 3.0 spec](openapi/weld-connect-openapi.json): 65 operations across 52 paths.
